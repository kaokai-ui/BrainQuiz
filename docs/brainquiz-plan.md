# BrainQuiz 網頁遊戲計畫

## 1. 需求摘要

本專案將現有的 [365_Brain.quiz.xlsx](/D:/Game/BrainQuiz/365_Brain.quiz.xlsx) 轉成一個可直接開啟的靜態網頁遊戲。

已確認的資料結構如下：

- Excel 共有五個工作表：`Monday`、`Tuesday`、`Wednesday`、`Thursday`、`Friday`
- 每個工作表共有 `366` 列，扣掉標題列後為 `365` 筆題目資料
- 每筆資料固定有兩欄：`題目`、`答案`

## 2. 核心玩法

### 2.1 題目來源

- 題目與答案資料會從 Excel 轉成前端可直接使用的資料檔
- 資料可獨立放在 `data/questions.js`，避免把大量內容全部塞進 `index.html`

### 2.2 顯示規則

- 使用者打開網頁後，系統依照「今天是星期幾」自動對應到同名工作表
- 例如今天是星期二，畫面就顯示 `Tuesday` 題庫中的當週題目
- 題目下方提供答案區塊，讓使用者查看正解

### 2.3 題目輪替規則

- 每個工作表各自維護一條獨立進度
- 例如：
  - 第一次打開星期二時，顯示 `Tuesday` 第 1 筆
  - 下次到了星期二，顯示 `Tuesday` 第 2 筆
  - 依此類推讀到第 365 筆後，再回到第 1 筆
- `Monday` 到 `Friday` 彼此互不影響，各走各的 365 週循環

### 2.4 當日顯示規則

- 只要仍是同一個台北日曆日，不管早上、下午或晚上進入頁面，看到的都必須是同一天的同一筆資料
- 題目切換時間點以 `Asia/Taipei` 為準
- 只有在台北時間跨日後，才允許切換到新的當日資料

## 3. 實作假設

以下為本次先採用的實作假設，之後可依你的回覆微調：

- 題目進度以「每個星期別的起始週」為基準，透過 `localStorage` 保存在瀏覽器本機
- 同一天重複打開頁面，不會跳到下一題
- 如果隔了數週才再次打開，題號會依經過的週數往後推進，而不是只前進 1 題
- 當天是否更換題目，以台北時間日期為唯一判斷依據，不使用使用者裝置本地時區
- 週末因原始題庫沒有 `Saturday` / `Sunday` 工作表，固定顯示休息頁，不自動派題
- 答案區先依需求預設顯示答案，並保留按鈕讓使用者自行收合

## 4. 已確認項目

- 週末一律顯示休息頁，不顯示 Friday 題目，也不預先顯示下一個 Monday 題目
- 答案區是否要維持目前做法：
  - 預設直接顯示答案
  - 允許使用者自行隱藏 / 再次顯示
- 是否需要加入：
  - 手動切換星期題庫
  - 重設進度按鈕
  - 答題計時或答對統計

## 6. 介面設計方向

- 單頁式設計，直接開啟 `index.html` 即可使用
- 首屏顯示：
  - 今日星期
  - 今日對應題庫名稱
  - 目前週次題號
  - 題目內容
  - 答案區
- 介面風格：
  - 明亮、有遊戲感
  - 行動裝置與桌機皆可閱讀
  - 題目文字保留換行與段落，方便閱讀較長的邏輯題

## 7. 實作步驟

1. 解析 Excel 檔並確認五個工作表格式一致
2. 撰寫轉檔腳本，輸出前端資料檔
3. 建立靜態網頁與遊戲 UI
4. 實作日期判斷與每週輪替邏輯
5. 固定以 `Asia/Taipei` 計算今日日期與換日時間
6. 加入本機進度保存機制
7. 驗證五個工作日的資料都能正確輪替
8. 補充使用說明與後續可擴充方向

## 8. 驗收標準

- 可直接在瀏覽器打開 `index.html`
- 能自動依照星期一到星期五顯示對應題庫
- 同一星期別能依週次順序前進
- 同一天內重整或重新開啟頁面，仍維持同一題不變
- 只有在台北時間跨日後，才會切換到新的當日資料
- 第 365 筆之後能回到第 1 筆
- 題目與答案內容完整保留 Excel 原文換行
- 關閉瀏覽器後重新開啟，進度仍可延續
